# 带你走进“X线下子宫输卵管造影（HSG）检查”

> 更新时间：2026-09-17 (UTC+8)

小宋夫妇备孕多年未果，趁着假期来山大生殖做不孕检查，与医生一番沟通之后，医生建议小宋做个X线下子宫输卵管造影检查，可小宋夫妇对子宫输卵管造影一无所知，下面就由小编带着小宋夫妇及广大病友一起来揭秘“X线下子宫输卵管造影”。
**什么是X 线下子宫输卵管造影（HSG）？**
X 线下子宫输卵管造影（HSG）是通过导管向宫腔及输卵管内注入造影剂，利用X线透视及摄片，显示造影剂的分布情况，从而了解输卵管时候通畅、阻塞部位及宫腔形态。

X 线下子宫输卵管造影（HSG）是诊断输卵管通畅性的首选，可以检查输卵管近端和远端的阻塞，显示峡部的结节性输卵管炎，了解输卵管的细节并评估输卵管周围的炎症情况。

**检查前准备**
1、完善术前化验：乙肝五项、丙肝、梅毒、艾滋、衣原体、阴道微生态评价、阴道B超、妇科检查。

2、最佳检查时间及费用：一般是月经干净后3-7天，干净后禁止同房。我院X线下子宫输卵管造影检查费用约900元。

3、提前预约：可通过我院手机客户端“医患服务平台”进行预约。如图所示：

4、请于造影前1天自测尿妊娠试验，确定未孕者方可行造影检查。

**检查日准备**
1、请务必按照预约时间准时到达预约地点。

2、请携带门诊病历以及外院化验单。

3、检查前请提前喝水，适当充盈膀胱。

**检查后注意事项**
1、检查后2周内禁盆浴、禁同房，并根据医嘱应用消炎药。

2、检查后可能会有少量阴道流血，可持续7天左右。若阴道流血超过7天或流血过多，请及时就诊。

**输卵管造影检查一天能完成吗？需要住院吗？**
答：术前化验上午查，下午即可出结果。结果正常且条件合适，当日可现场预约，一天就能完成。输卵管造影检查无需住院。

**输卵管造影疼吗？可以打麻药吗？**
答：检查过程中会有一些不舒服，类似痛经的感觉，下腹会有坠胀感，做完后不久即可恢复。输卵管造影一般不需要注射麻醉药物。
**输卵管造影检查做完后多久可以备孕？**
答：当月做完输卵管造影检查，下个月即可正常备孕
