# 【朝医新闻】解放军总医院京中医疗区来院调研交流

> 更新时间：2026-09-16 (UTC+8)

2024年6月12日，解放军总医院京中医疗区主任徐皎皎、副主任杨光等一行来到首都医科大学附属北京朝阳医院（以下简称朝阳医院）参与调研交流会。朝阳医院党委委员、副院长梅雪，门诊办公室主任张玉华，急诊医学中心副主任王军宇、护士长赵丽新等人热情接待来访团队。

座谈会上，梅雪首先代表朝阳医院对解放军总医院京中医疗区一行的到来表示热烈欢迎。他详细介绍了朝阳医院急诊医学中心的建设情况、急诊相关制度的完善以及急诊教学培训的开展情况。特别强调近年来，急诊医学中心在郭树彬教授的带领下，对整个急诊流程进行的创新改造。朝阳医院急诊率先在北京市范围内推行了急诊区域电子化分级诊疗模式，这一创新举措为急诊患者提供了更加高效、精准的医疗服务。随后，该模式在北京市医院管理中心范围内的22家医院得到了推广。

此次调研交流就急诊分级诊疗的相关制度和设置等议题进行深入交流和讨论。会后，在王军宇、赵丽新等人的陪同下，解放军总医院京中医疗区队对朝阳医院急诊医学中心进行实地参观学习。

急诊医学中心 康晨瑜 赵丽新
